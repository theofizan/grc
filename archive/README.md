# Archived OFDM project

`ofdm_2026-10-17/` preserves the project immediately before the switch to flat, stock-block single-carrier examples. It includes all seven prior top-level flowcharts, four project hierarchical modules, Python/MATLAB code, documentation, reference settings, validation logs, and results.

The inner README describes that historical snapshot; its software validation claims apply to its archived sources. This archive is outside the active launcher's search. To resume it later, restore the snapshot into a separate working directory and configure its Python package there. Some launch paths and the original terminal setup refer to the former project location and will need adjustment.
